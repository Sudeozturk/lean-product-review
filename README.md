# Lean — Product Review

An independent review of a calorie and macro tracking app, written from the
perspective of a user going through onboarding for the first time.

Based only on public sources: the released app, its store listing, the
published methodology page and the terms of use.

## Contents

- [`product-review.pdf`](product-review.pdf) — five findings from the onboarding
  flow, three of them verified by controlled tests.
- [`product-requirements.pdf`](product-requirements.pdf) — requirements,
  acceptance criteria and an experiment plan for one of the findings.
- [`ga4-bigquery-analiz-notlari.md`](ga4-bigquery-analiz-notlari.md) — funnel
  and cohort retention analysis on Google's public GA4 ecommerce dataset,
  written in BigQuery. Includes a measurement error I made and how I caught it.
